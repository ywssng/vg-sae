# Legacy four-method results

The CSV and PNG files in this directory predate the SAELens v6.47.0 baseline
update. They contain only VG-SAE, L1-ReLU, TopK, and the former Gated SAE and
are preserved for reproducibility; they are not six-method comparison results.

The revised notebook writes its VG-SAE, L1-ReLU, TopK, BatchTopK, JumpReLU,
and Gated SAE results to the sibling `exp07_saelens_v647_six_method/`
directory so these legacy artifacts cannot be mistaken for current output.
